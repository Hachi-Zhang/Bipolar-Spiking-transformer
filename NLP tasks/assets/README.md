# External assets

Model weights, tokenizer files, pretraining corpora, GLUE datasets, Hugging Face caches, and experiment outputs are intentionally excluded.

Pass them explicitly to scripts with `--model_name_or_path`, `--dataset_path`, and `--checkpoint`. The original local assets remain under `/data/260010055/LoopTransformer/spikelm/spikeLM-BERT` and are not duplicated here.
